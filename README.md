# لوحة العادات — القرآن والإنجليزية

Next.js 14 + Supabase + Vercel. واجهة عربية RTL، تسجيل دخول باسم مستخدم وكلمة مرور، ولي أمر (مسؤول) يرى إنجاز الجميع، وكل عضو يرى جدوله فقط.

## المزايا
- مهام ديناميكية: إضافة/تعديل/حذف، وتكرار (مرة، يوميًا، أسبوعيًا، كل أسبوعين، شهريًا، سنويًا) مع تاريخ نهاية اختياري.
- حذف تكرار واحد بـ«تخطي هذا اليوم» أو حذف المهمة كلها.
- عروض: اليوم، الأسبوع، الشهر، السنة (خريطة حرارية).
- ملاحظات، تقييم فهم 1–5، «يحتاج مراجعة» لكل مهمة.
- قالب «خطة الإنجليزية 35 يومًا» حرفيًا من الوثيقة، يُطبَّق على أي أخ بتاريخ بداية يوم أحد.
- ولي الأمر: إنشاء الحسابات، تغيير كلمات المرور، حذف حساب، تطبيق قالب لأي أخ، وعرض جدوله وتعديله.

## الإعداد (مرة واحدة، بحساب أخيك)
1. **Supabase**: أنشئ مشروعًا. افتح SQL Editor والصق محتوى `supabase/schema.sql` ثم Run.
2. **Authentication → Providers → Email**: عطّل «Confirm email». وفي **Sign In / Providers** عطّل «Allow new users to sign up» (الحسابات يُنشئها المسؤول فقط).
3. **أول حساب (ولي الأمر)**: Authentication → Users → Add user → Create new user، البريد `اسم_المستخدم@habits.example.com` (مثلًا `abdullah@habits.example.com`) وكلمة مرور، مع تفعيل Auto Confirm. أول حساب يُنشأ يصبح مسؤولًا تلقائيًا. بعده يضيف الباقين من صفحة «الإدارة».
4. **GitHub**: ارفع محتوى هذا المجلد إلى مستودع `senduabod2030-lab/Abdullah` (في الجذر).
5. **Vercel**: Import للمستودع، Framework = Next.js، وأضف المتغيرات من `.env.example`:
   - `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY` و `SUPABASE_SERVICE_ROLE_KEY` من Project Settings → API (الأخير سري، لا تضعه في الكود).
   - `NEXT_PUBLIC_AUTH_DOMAIN=habits.example.com` (نفس النطاق المستخدم في البريد الداخلي؛ لا يُرسل إليه شيء).
6. Deploy، ثم ادخل باسم المستخدم وكلمة المرور.

## التشغيل محليًا
```
cp .env.example .env.local   # عبّئ القيم
npm install
npm run dev
npm run check:template       # فحص أرقام خطة الإنجليزية
```

## ملاحظات
- أسماء المستخدمين: حروف إنجليزية صغيرة وأرقام و `._-` (3–20). الاسم الظاهر يمكن أن يكون عربيًا.
- الأمان بالكامل في Supabase عبر RLS: العضو لا يقرأ أو يكتب إلا بياناته، والمسؤول يصل للجميع.
- لإضافة قالب جديد (القرآن) أضف ملفه في `lib/templates` وسجّله في `lib/templates/index.ts`.
